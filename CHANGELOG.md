# Changelog

## 0.3.1 — first public release preparation, 2026-10-14

- Coordinated Obsidian Celluloid (Light) and Obsidian Celluloid Noir native themes.
- Comprehensive workbench colors, TextMate and semantic highlighting, and terminal ANSI palettes.
- Original shared file icon theme with 45 glyphs and broad document, office, data, code, tooling, archive, media, design and research coverage.
- Optional typography/layout and native appearance-switching presets.
- Original scalable OC branding, 256×256 Marketplace icon, and real Light/Noir VS Code screenshots.
- Release metadata, licensing, package exclusions and privacy/reference checks.
- Corrected release validation to use the current manifest identity and reject obsolete VSIX packages.
- Preserved strict required-document checks and all appearance baselines.

Release identity: `zmmartins.obsidian-celluloid@0.3.1`.
Repository: https://github.com/zmmartins/obsidian-celluloid-vscode.
The v0.2/v0.3.0 appearance baselines record historical design snapshots; they do
